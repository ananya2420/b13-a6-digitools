# 🛒 Smart Cart React App

A modern and responsive e-commerce UI built with React.js. This project allows users to browse products, add them to a cart, and manage their selections with a smooth and interactive experience.

---

## 🌐 Live Site
👉 https://your-live-link.com

---

## 📦 Features

✨ Interactive Product & Cart Toggle  
Users can switch between product view and cart view seamlessly.

🛒 Cart Functionality  
Add, remove, and checkout products with real-time updates and toast notifications.

📊 Dynamic Product Data  
Products are loaded from JSON with details like price, tags, features, and subscription type.

---

## 🧩 Project Highlights

- Responsive Navbar with Cart Count
- Banner Section with CTA buttons
- Stats Section
- Product Cards (3-column layout)
- Cart System with Remove & Checkout
- Toast Notifications (React-Toastify)
- Fully Responsive Design

## ⚙️ Technologies Used
